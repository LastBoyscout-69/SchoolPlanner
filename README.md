# SchoolPlanner

Генератор школьного расписания для школ. Работает на Windows.

## 📥 Скачать

Последняя версия: **[v2.0.0](https://github.com/LastBoyscout-69/SchoolPlanner/releases/latest)**

## ✨ Возможности

- 📅 Составление расписания (на базе OR-Tools)
- 👩‍🏫 Учителя, классы, предметы, кабинеты
- 🚫 Запрещённые слоты у учителей (методический день)
- 🔍 Умный советчик — покажет, что не так
- ✏️ Перетаскивание уроков (клик → клик)
- 🎨 Цветные ячейки по предметам
- 🔑 Демо-версия (до 5 классов) + активация
- 💾 Сохранение данных в JSON

## 🖥️ Системные требования

- Windows 10/11 (64-бит)
- 4 ГБ ОЗУ
- Интернет не требуется

## 🚀 Как запустить

1. Скачайте `.exe` из раздела **Releases**.
2. Запустите двойным кликом.
3. **Первый запуск может занять 5–15 секунд** (распаковка).
4. Если Windows показывает **синее окно** «Windows защитила ваш компьютер» → нажмите **«Подробнее»** → **«Выполнить в любом случае»**.

## 📖 Как пользоваться

1. Вкладка **👩‍🏫 Учителя** — добавьте учителей и их предметы.
2. Вкладка **🏫 Классы** — добавьте классы.
3. Вкладка **📚 Предметы** — задайте часы по каждому предмету.
4. Вкладка **🚪 Кабинеты** — добавьте кабинеты.
5. Вкладка **📅 Расписание** — нажмите **«🚀 Составить расписание»**.

Подробности — на вкладке **❓ Справка** внутри программы.

## 🔑 Демо-версия и активация

- **Демо-режим**: до 5 классов в расписании.
- **Полная версия**: без ограничений.
- Для получения ключа активации — свяжитесь с разработчиком.
